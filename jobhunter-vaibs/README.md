## Running Locally
```bash
cd jobhunter-vaibs
python3 app.py
```
Open [http://localhost:8085](http://localhost:8085) in your browser.

## Deploying on Render (Online)
1. Push this repository to GitHub.
2. In Render dashboard (https://render.com), choose **New > Blueprint** or **New > Web Service**.
3. Select your repository. The included `render.yaml` automatically configures the web service on Render's free tier.
4. Your application will be live at `https://jobhunter-vaibs.onrender.com`.
