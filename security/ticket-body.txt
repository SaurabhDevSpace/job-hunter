1. SUMMARY
--------------------------------------------------------------------
The host endpoint agent is terminating the Python interpreters used for
Blue Planet Advisor (BPA) development on my workstation, and is refusing
to memory-map the compiled Python extension modules those projects
depend on. This blocks day-to-day development across the BPA Python
repositories.

Two distinct behaviours are observed:

  (A) Process termination - the interpreter is SIGKILLed immediately on
      launch. The shell reports "Killed: 9", exit code 137, with no
      output. An agent popup names the binary.

  (B) Memory-mapping denial - compiled Python extension modules (.so)
      fail to load with:
        dlopen(...): mmap(size=...) failed with errno=1
      and Apple's own tooling reports:
        lipo: can't map input file (Operation not permitted)

Re-verified 2026-09-01: every interpreter listed in section 2 still
returns exit code 137.

5. WHY THIS IS AN ALLOWLIST GAP, NOT A DETECTION
--------------------------------------------------------------------
Under default-deny application control, the decision is made by file
hash against an approved list - not by any judgement that a file is
malicious. That accounts for every observation below, each of which
looked anomalous while the cause was assumed to be malware detection:

  - Copying a blocked .so to /tmp did not help. The hash is unchanged,
    so it is still not on the list.
  - Ad-hoc re-signing (codesign -f -s -) did not help. Re-signing does
    not add a file to the allowlist.
  - A trivial C extension compiled locally on this machine was also
    refused. A brand-new binary is by definition not on the list.
  - Three copies of ripgrep run while two do not (section 3). The
    working copies were captured during baselining; the newer ones
    never were.
  - No quarantine extended attributes (xattr) are present, confirming
    this was never macOS Gatekeeper.
  - Other native modules load normally: uvloop, httptools,
    markupsafe._speedups, yaml._yaml, _sqlite3, _ssl. These were
    baselined; the blocked ones were not.

All affected files are unmodified official releases (python.org /
Anaconda / PyPI / the GitHub Copilot CLI distribution). The same
versions run without incident on colleagues' machines and in CI. The
SHA-256 values in this request can be checked against VirusTotal.

No malicious behaviour is alleged or suspected by the agent; these files
are simply absent from the approved application list.
